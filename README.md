# ITS Time System

The ITS time system defines a custom time scale anchored to the Earth's rotation (UT1) and an astronomical event: the earliest nightfall in Novosibirsk, Russia.

## Overview

The zero point of ITS time is not an arbitrary UTC midnight — it is the earliest astronomical nightfall (Sun altitude < -108°, i.e. the end of evening astronomical twilight) observed in Novosibirsk (latitude 55.03° N, longitude 82.93° E) over the 50-year window 1976–2026. The UT1 second-of-day of that event is stored in `offset.dat` (44193.792289 sec ≈ 12:16:33 UT1).

ITS time is a signed integer of nanoseconds elapsed since that instant. It uses UT1 (Universal Time), which tracks the actual rotation of the Earth, rather than UTC alone. The difference UT1−UTC (called DUT1) is obtained from the IERS `finals.all` file and interpolated with a natural cubic spline to arbitrary timestamps, giving sub-millisecond precision for the conversion.

## Consistency

- All three binaries (`its`, `itstime`, `its-offset`) use the same astronomical code and DUT1 spline (in `common.c`). For a given `finals.all` and `offset.dat` they produce identical delta values.
- The calendar is purely derived from the nanosecond delta using floor division:
  - 1 ITS day = 86400 SI seconds (counted in UT1)
  - 1 ITS year = 147 days, 1 ITS month = 21 days (7 months per year, numbered from 0)
  - `years = days / 147`, `months = (days % 147) / 21`, `days_rem = (days % 147) % 21`
  - Time of day = remaining fraction of the current day as HH:MM:SS
- The GMP-based binary `its` provides exact arbitrary-precision arithmetic for the nanosecond counter. The lightweight `itstime` uses 64-bit integers; both give the same result for the foreseeable range.
- When `offset.dat` is missing, `get_offset()` spawns `its-offset` to regenerate it, guaranteeing that the epoch offset is always available and consistent.

## Specifications

| Parameter          | Value                  | Description                              |
|--------------------|------------------------|------------------------------------------|
| Epoch date         | 2026-06-22 00:00:00 UTC| Notional UTC epoch                       |
| Epoch offset       | 44193.792289 UT1 sec   | Earliest nightfall → UT1 seconds of day  |
| True epoch start   | 2026-06-22 ≈12:16:33 UT1| ITS day 0 instant                        |
| ITS day            | 86 400 SI seconds      | Counted in UT1                           |
| ITS year           | 147 days               | 7 months of 21 days each                 |
| ITS month          | 21 days                | Numbered 0–6                             |
| Time resolution    | 1 nanosecond           | Signed 64-bit or arbitrary-precision     |
| DUT1 data          | IERS finals.all        | Natural cubic spline interpolation       |
| Latitude / Lon.    | 55.03 N / 82.93 E      | Novosibirsk, Russia                      |
| Twilight angle     | 108° (astronomical)    | Sun center < -108°                       |

## Building

Prerequisites: a C compiler, standard math library (`-lm`), and GMP (`-lgmp`).

```sh
make
```

This builds all three binaries. The compiler can be overridden:

```sh
make CC=gcc CFLAGS="-O2 -march=native"
```

Clean:

```sh
make clean
```

## Binaries

### `its` — base implementation

Full-featured reference implementation using GNU Multiple Precision Arithmetic (GMP). Output includes the day-start offset, earliest-night metadata, the raw nanosecond delta as an arbitrary-precision integer, and the human-readable ITS calendar date.

```
./its
```

Example output:
```
Day start offset: 44193.792289 UT1 sec (12:16:33)
Earliest night: 2026-12-12 starts at 12:16:33 UTC
Nanoseconds since epoch start: 1457528395242816
ITS time: 0y 0m 16d 20:52:08
```

### `itstime` — Unix-style binary

Lightweight version with classic Unix tool behaviour. By default it prints a single integer (nanoseconds), suitable for scripting:

```
$ ./itstime
1457528395242816
```

With `-h` (human-readable):
```
$ ./itstime -h
0y 0m 16d 20:52:08
```

With `-j` (Japanese notation):
```
$ ./itstime -j
0年0月16日20時52分08秒
```

### `its-offset` — offset generator

Computes the astronomical offset across the 1976–2026 window (50 years of daily twilight calculations) and writes the result to `offset.dat`. Run manually if `offset.dat` becomes corrupted or needs regeneration:

```sh
./its-offset
```

It is also invoked automatically by `its` and `itstime` when `offset.dat` is absent.

## Required data files

- **`offset.dat`** — Generated by `its-offset`; a single floating-point number (UT1 seconds of day of the earliest nightfall). Must be present in the working directory (auto-generated otherwise).
- **`finals.all`** — IERS Earth orientation parameter file (bulletin B). Obtain from <https://datacenter.iers.org/data/latest/finals.all> or place your own copy. The program reads columns 8–15 (MJD) and 58–67 (DUT1).
