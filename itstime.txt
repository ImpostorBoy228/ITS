================================================================================
                    ITS TIME SYSTEM – README
================================================================================

1. INTRODUCTION
-------------------------------------------------------------------------------

The ITS time system defines a custom time scale based on the astronomical
"start of the day" in Novosibirsk, Russia (latitude 55.03° N, longitude 82.93° E).
The epoch is set to 2026-06-22 00:00:00 UTC, but the zero point of the ITS
time is not UTC midnight – it is the earliest astronomical nightfall (twilight
end) observed in Novosibirsk over the 50‑year period from 1976 to 2026.

The program `itstime` reads pre‑computed data (`offset.dat` and `finals.all`)
and returns the current ITS time as nanoseconds elapsed since that epoch.
It can also print a human‑readable format using a custom calendar.

-------------------------------------------------------------------------------

2. HOW IT WORKS
-------------------------------------------------------------------------------

2.1 Determining the start of the day
------------------------------------
The start of an ITS day is defined as the beginning of the earliest
astronomical night (when the Sun is 108° below the horizon) that occurs
in Novosibirsk during the 50‑year window (1976–2026). For each day,
the time of the end of evening twilight (Sun altitude < -108°) is computed.
The minimum of all these times (in UT1 seconds of the day) gives the
offset from UTC midnight. This value is stored in `offset.dat`.

In Novosibirsk, due to high latitude, the earliest nightfall occurs around
12:16:33 UT1 (the value used in the example). This means that ITS day 0
begins at 2026-06-22 12:16:33 UT1 (approximately), not at UTC midnight.

2.2 Time representation
-----------------------
ITS time is stored as a signed 64‑bit integer of nanoseconds elapsed since
the epoch start (the UT1 instant defined above). It can be positive (future)
or negative (past).

2.3 UT1 and Earth rotation
---------------------------
The calculation uses UT1 (Universal Time), which accounts for the irregular
rotation of the Earth. The difference UT1‑UTC (called DUT1) is obtained from
the IERS `finals.all` file. Cubic spline interpolation is applied between
daily values to get DUT1 at arbitrary moments with high precision.

2.4 The `offset.dat` file
-------------------------
This is a plain text file containing a single floating‑point number:
the offset in UT1 seconds from UTC midnight to the earliest nightfall.
It is generated once by a separate program (not included here) that performs
the astronomical computations for the whole 50‑year period.

If this file is missing or invalid, `itstime` will exit with an error.

2.5 `finals.all` and interpolation
----------------------------------
`finals.all` is the standard IERS Earth orientation parameter file.
It contains daily values of DUT1 (and other parameters). The program:
- reads all valid lines
- builds a natural cubic spline for DUT1 as a function of MJD
- evaluates the spline at the epoch and at the current time
- uses these values to convert UTC moments to UT1 moments

-------------------------------------------------------------------------------

3. BUILDING AND RUNNING
-------------------------------------------------------------------------------

Prerequisites:
- A C compiler (gcc recommended)
- Standard C library with math support (`-lm`)
- On some systems, `-lrt` may be needed for `clock_gettime`

Compilation:
    gcc -o itstime itstime.c -lm

If you encounter linking errors for `clock_gettime`, add `-lrt`:
    gcc -o itstime itstime.c -lm -lrt

The program expects two files in the current working directory:
- `offset.dat` (generated by the companion astronomical tool)
- `finals.all` (obtainable from https://datacenter.iers.org/)

If either file is missing, the program will terminate with an error message.

-------------------------------------------------------------------------------

4. USAGE
-------------------------------------------------------------------------------

Run without arguments:
    ./itstime

Output: a single signed integer – the number of nanoseconds elapsed since
the ITS epoch start.

Run with the `-h` flag for human‑readable format:
    ./itstime -h

Output: a formatted date and time in the custom ITS calendar:
    <years>y <months>m <days>d HH:MM:SS

Example:
    0y 0m 16d 05:09:42

-------------------------------------------------------------------------------

5. CALENDAR SPECIFICS
-------------------------------------------------------------------------------

The ITS calendar is not the Gregorian or Julian calendar. It was designed
for simplicity and is based on the following rules:

- 1 ITS year   = 147 days
- 1 ITS month  =  21 days
- 1 ITS day    = 86400 seconds (SI seconds, but counted in UT1)

Thus a year consists of exactly 7 months (7 × 21 = 147).
Months are not named – they are simply numbered from 0 to 6.
The epoch (year 0, month 0, day 0) begins at the earliest nightfall
of 2026-06-22 (UT1).

Dates before the epoch are represented with negative year, month, day values,
but the implementation currently only handles positive deltas (it prints
the floor division; for negative values it may not be intuitive – use
the raw nanoseconds for absolute precision).

The human‑readable output is produced by:
- dividing the total seconds (or nanoseconds) by the length of a day (86,400 s)
- taking the quotient as days
- computing years = days / 147, months = (days % 147) / 21, days_rem = (days % 147) % 21
- the time of day is the remaining seconds within the current day (HH:MM:SS)

This calendar is arbitrary but deterministic and easy to convert to/from
the raw nanosecond count.

-------------------------------------------------------------------------------

6. EXAMPLE OUTPUT
-------------------------------------------------------------------------------

Assuming the current UTC time is 2026-07-08 17:26:15, and the offset is 12:16:33 UT1,
the program will compute:

$ ./itstime
1400982143470376

$ ./itstime -h
0y 0m 16d 05:09:42

Explanation:
- The epoch start is 2026-06-22 12:16:33 UT1.
- The current time is 2026-07-08 17:26:15 UTC, which is about 16.2 days later.
- The remaining time of day (05:09:42) is the time since the start of the current ITS day.

-------------------------------------------------------------------------------

7. DEPENDENCIES AND FILE FORMATS
-------------------------------------------------------------------------------

7.1 offset.dat
--------------
One line containing a decimal number (e.g., 44193.792289).
It is the UT1 second of day (0..86400) of the earliest nightfall.

7.2 finals.all
---------------
Standard IERS format (see https://datacenter.iers.org/data/latest/finals.all).
The program parses:
- columns 8‑15: MJD (Modified Julian Date)
- columns 58‑67: DUT1 value (seconds, with sign)
Lines starting with "MJD" are skipped, as are lines with invalid values.

The spline interpolation requires at least two data points.
